# data/

| Folder      | Contents                                                        |
|-------------|-----------------------------------------------------------------|
| `raw/`      | Raw CIC-IDS2017 CSVs (or the auto-discovered dataset folder)    |
| `processed/`| Cleaned + normalized data, train/test splits and demo sample    |

`processed/` artifacts are generated by `src/preprocessing.py` and are **not
committed to git** (see `.gitignore`). Generated files:

```
processed/
├── cic_ids2017_cleaned.csv.gz   all cleaned rows (features + Label + LabelGroup)
├── train.csv.gz                 stratified 80% train split
├── test.csv.gz                  stratified 20% test split
├── demo_sample_40k.csv          stratified 40k demo sample
└── processed_info.json          shapes, splits and pipeline log
```

Everything in `processed/` is derived from the **real** CIC-IDS2017 CSVs; no
synthetic samples are generated.
